# Novelty / Research Framing

The prototype focuses on the integration and demonstration of:

1. Patient-specific risk trajectory and deterioration velocity.
2. Explainable factors and a visible “why now” signal.
3. Data-confidence awareness based on missingness.
4. Nurse-facing dynamic priority queues.
5. Clinician-in-the-loop review and auditability.
6. A research replay path from real PhysioNet hourly records into the monitoring interface.

These components should not be described as individually unprecedented without a prior-art search. A paper or patent application should emphasize the specific system architecture, interaction logic, technical implementation and experimentally evaluated workflow.
